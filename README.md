## 다운로드

[릴리스 목록](https://github.com/illililiiililii/Alauncher/releases)에서 버전을 선택하고 **Assets**를 펼치세요.

- **설치형**은 파일 이름이 `-setup.exe`로 끝납니다. **실행형**은 설치 없이 열 수 있는 별도의 `.exe`입니다.
- 아래 기능은 [0.2.13 개발 미리보기](https://github.com/illililiiililii/Alauncher/releases/tag/v0.2.13) 기준입니다. 버전별 변경 사항과 확인된 범위는 각 릴리스에 있습니다.
- 런처에서 미리보기를 찾으려면 **설정 → 정보 → 업데이트 확인**에서 **개발 미리보기도 확인**을 선택하세요.

## 현재 기능

### 인스턴스와 게임 실행

- Minecraft 버전과 로더별로 인스턴스를 만들고 복제·삭제하거나 즐겨찾기에 추가할 수 있습니다. 검색과 즐겨찾기 필터를 지원합니다.
- Vanilla, Fabric, Forge, NeoForge, OptiFine을 선택할 수 있습니다. 버전과 로더의 조합에 따라 설치 가능 여부가 달라집니다. 지원 형식의 사용자 지정 버전 JSON을 가져오고 호환되는 Java를 찾아 설치할 수 있습니다.
- 독립 게임 폴더를 사용하거나, 직접 선택해 공식 Minecraft 폴더와 통합하거나, 다른 인스턴스의 지정 폴더를 공유할 수 있습니다. 기존 공식 런처의 설치 구성과 선택한 월드·설정·콘텐츠를 독립 인스턴스로 복사할 수도 있습니다.
- 인스턴스별 Java, RAM, JVM 인수, 해상도와 전체 화면을 설정할 수 있습니다. 실행 프리셋을 만들고 편집·복제·삭제하거나 공유용 JSON으로 내보낼 수 있습니다. 저장한 설정은 이번 실행에만 쓰거나 기본값에 반영할 수 있습니다. 게임 시작 시 런처 창을 어떻게 둘지도 선택할 수 있습니다.
- 인스턴스를 만들고 바로 실행하거나 콘텐츠 추가·설정으로 이동할 수 있습니다. 다운로드와 실행 준비의 진행률, 취소, 작업 기록도 지원합니다.

### 계정과 스킨

- Microsoft 계정으로 로그인하고 런처의 기본 계정을 전환할 수 있습니다. Minecraft 소유권과 Java 프로필 확인을 거치며, 로그인 자격 증명은 Windows 자격 증명 저장소로 보호합니다. 로컬 테스트용 오프라인 프로필도 제공합니다.
- PNG 스킨을 클래식(Steve)·슬림(Alex) 모델로 3D 미리보기 할 수 있습니다. 회전·확대, 전신·얼굴 보기, 애니메이션, 망토·배경 설정과 미리보기 PNG 저장을 지원합니다. 로그인한 계정에 스킨을 적용할 때는 대상과 변경 내용을 확인합니다.

### 콘텐츠 탐색과 설치

- Modrinth에서 모드, 모드팩, 리소스팩, 셰이더를 검색어 없이 둘러보거나 검색할 수 있습니다. 자동·수동 검색, 카테고리, 페이지 이동, 다운로드·관련도·업로드·업데이트·팔로워 정렬을 제공합니다.
- 프로젝트의 설명·라이선스·스크린샷·변경 기록과 제공되는 호환 정보를 확인할 수 있습니다. Modrinth 프로젝트나 버전 링크를 붙여넣거나, 탐색에서 설치할 버전과 대상 인스턴스를 고를 수 있습니다.
- 종류별 즐겨찾기와 최근 본 항목을 이 PC에서 관리할 수 있습니다. 리소스팩·셰이더의 인기·새 업로드 바로가기와 셰이더 부하별 바로가기를 고를 수 있습니다. 최근 기록은 종류별로 끄거나 지울 수 있습니다.

### 모드와 팩 관리

- 로컬 JAR을 여러 개 추가하고, 설치된 모드를 가상 폴더로 분류해 옮기거나 일괄로 켜고 끌 수 있습니다. 설치·제거·업데이트 전에 알려진 의존성과 충돌, 변경 파일을 검토할 수 있습니다.
- 개별 모드 버전을 고정할 수 있습니다. 업데이트 정책은 전체·인스턴스·모드별로 안정판, 베타, 알파, 현재 버전 유지, 알림 전용 중 선택할 수 있습니다.
- 지원 범위의 `.mrpack`을 가져오거나 내보내고, 팩과 현재 인스턴스의 차이를 비교한 뒤 백업을 거쳐 동기화할 수 있습니다. 연결된 팩의 업데이트를 확인하거나 누락·손상된 JAR만 골라 복구할 수 있습니다.
- 리소스팩·셰이더 ZIP을 Modrinth나 로컬 파일에서 추가하고, 켜거나 끄거나 보관 후 복원할 수 있습니다. 셰이더를 게임에서 사용하려면 호환되는 Iris 또는 OptiFine이 필요합니다.
- 동일한 Modrinth JAR의 무결성을 확인해 다시 다운로드하는 대신 공유 캐시에서 재사용할 수 있습니다.

### 월드, 스크린샷, 플레이 기록

- 월드 센터에서 인스턴스별 월드 이름, 아이콘, 버전, 게임 모드, 최근 플레이 날짜와 크기를 확인하고 폴더를 열 수 있습니다. 월드 센터는 읽기 전용입니다.
- 스크린샷을 인스턴스별로 검색·날짜순 정렬하고, PNG를 미리 보거나 새 복사본으로 내보낼 수 있습니다.
- 전체·인스턴스별 플레이 시간과 최근 실행 기록을 이 PC에서 확인할 수 있습니다. 플레이 시간은 게임 프로세스가 실행된 시간을 기준으로 집계합니다.

### 백업, 저장 공간, 다운로드

- 수동 스냅샷과 선택형 유휴 자동 백업을 만들고, 이전 상태를 검토해 복원하거나 보관 개수를 설정할 수 있습니다. 지원되는 모드·팩·그래픽 변경은 적용 전에 보호 백업을 사용합니다.
- 드라이브 전체와 런처 데이터의 사용량을 각각 확인하고, 항목별 파일 상세를 열거나 정리할 캐시와 보관 항목을 골라 예상 용량을 확인할 수 있습니다. 런처 데이터 위치를 복사·검증 후 이전할 수도 있습니다.
- 다운로드 화면에서 작업 진행률과 기록을 확인하고, 지원되는 작업은 일시 정지·재개·취소할 수 있습니다. 다운로드 파일은 작업에 맞는 해시로 검증합니다.

### 개인화와 접근성

- 홈 위젯을 이동·크기 조절·숨김·고정할 수 있습니다. 배치를 프리셋으로 저장하거나 초기화할 수 있으며, 플레이·최근/즐겨찾기 인스턴스·스크린샷·다운로드·월드 등 자주 쓰는 기능을 배치할 수 있습니다.
- 라이트·다크·시스템 모드, 클래식을 포함한 디자인 테마, 애니메이션 설정을 선택할 수 있습니다. 접는 탐색, 키보드 탐색, `Ctrl+K` 빠른 작업과 설정 검색을 지원합니다.

### PC 최적화와 문제 진단

- CPU·GPU·메모리·디스크·Java 상태와 게임 설정을 확인하고 RAM·JVM·그래픽·호환 성능 모드 추천을 볼 수 있습니다. 지원되는 RAM·그래픽 변경은 내용을 검토한 뒤 적용하거나 복원할 수 있습니다.
- 게임 프로세스의 CPU·메모리 사용량을 선택해서 모니터링할 수 있습니다. 실행 오류가 나면 관련 로그·크래시 보고서와 가능한 원인, 해결 방법, 지원되는 파일 검사·복구 동작을 확인할 수 있습니다.
- 선택형 로컬 AI 도우미는 호환 장치에서 별도로 모델을 설치하면 모드 검색, 오류 설명, 설정 초안 제안을 돕습니다. 변경 사항의 적용은 사용자가 확인합니다.

### 친구 직접 연결과 서버

- 친구 코드로 요청을 보내고 수락·거절할 수 있습니다. 친구를 삭제하거나 차단할 수도 있습니다. 온라인·게임 상태와 버전을 친구별로 공개할 수 있습니다.
- 실험 기능으로 Minecraft에서 LAN에 공개한 싱글플레이 월드에 친구를 초대할 수 있습니다. 서로 직접 연결이 가능한 네트워크와 같은 Minecraft·로더 버전이 필요하며, 실제 접속은 게임의 **직접 연결**에서 합니다.
- 로컬 전용 서버는 Vanilla, Paper, Purpur, Fabric, Forge, NeoForge 또는 지원되는 사용자 JAR로 구성할 수 있습니다. 콘솔, 저장 후 종료·재시작, 플레이어·운영진·허용/차단 목록, 접속 진단, 백업을 관리할 수 있습니다. 서버 시작에는 Minecraft EULA 동의가 필요합니다.

### 런처 업데이트

- 정식 버전을 수동 또는 선택형 자동 확인으로 확인할 수 있습니다. 수동 확인에는 개발 미리보기도 포함할 수 있습니다.
- 적용 전에 버전과 변경 내용을 검토하고, 동의 후 서명된 업데이트 안내와 파일 무결성을 확인합니다. 지원되는 적용 방식은 시작 확인에 실패하면 이전 런처로 복구할 수 있습니다.
