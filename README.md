## 🌿 개발 미리보기에서 할 수 있는 일

| 기능 | 할 수 있는 일 |
| --- | --- |
| 🎮 **인스턴스** | Minecraft 버전과 모드 로더별로 독립된 게임 환경을 만들고, 실행 설정을 프리셋으로 저장합니다. |
| 🧩 **콘텐츠** | Modrinth에서 모드·모드팩·리소스팩·셰이더를 찾거나 링크를 붙여넣고, 설치 전에 대상과 버전을 확인합니다. |
| 🎨 **개인화** | 홈 위젯을 옮기고 스킨을 3D로 미리 봅니다. |
| 💾 **저장 공간** | 사용량을 항목별로 확인하고, 추적 중인 모드팩의 누락·손상 파일만 골라 복구합니다. |

## ⬇️ 다운로드

[릴리스 목록](https://github.com/illililiiililii/Alauncher/releases)에서 원하는 버전의 **Assets**를 펼치세요.

- **설치형** · `-setup.exe`를 내려받아 설치합니다.
- **실행형** · 설치 없이 실행하려면 이름 끝에 `-setup`이 없는 `.exe`를 받습니다.

개발 미리보기의 변경 내역은 각 릴리스에 있습니다. 런처에서 찾으려면 업데이트 확인 화면의 **개발 미리보기도 확인**을 선택하세요.
