# ALauncher

ALauncher는 Minecraft Java Edition의 인스턴스, 모드, 리소스팩, 셰이더와 저장 공간을 관리하는 Windows 런처입니다.

[Windows 실행 파일 및 설치 파일 다운로드](https://github.com/illililiiililii/Alauncher/releases)

개발 미리보기는 Releases에서 버전별 변경 내역과 함께 제공합니다. 런처 내에서 미리보기를 찾으려면 업데이트 확인 화면에서 **개발 미리보기도 확인**을 선택하세요.

공식 배포본은 개인적으로 무료 이용할 수 있습니다. 소스코드는 비공개입니다. 소스 접근, 프로젝트의 상업적 활용이나 다른 서비스에 통합하려면 권리자에게 문의하고 사전 서면 계약을 체결해 주세요. [라이선스 및 계약 안내](LICENSE.md) · [권리자 프로필](https://github.com/illililiiililii)

ALauncher는 Mojang 또는 Microsoft의 공식 제품이 아닙니다.
